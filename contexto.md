# UMBRAL AGENCIA IA — PRODUCTOS INICIALES
## Umbral Express: Web Express + Landing Express

## 1. Contexto general

Umbral Agencia IA comienza con una oferta sencilla, rápida y accesible para emprendedores y pequeños negocios.

La estrategia inicial es lanzar una **Campaña de Digitalización para Emprendedores y Pequeños Negocios**, utilizando productos express que puedan producirse rápidamente mediante procesos y proyectos reutilizables.

La intención no es posicionar a Umbral como una agencia que vende “webs baratas”, sino como una agencia que ayuda a negocios pequeños a dar un **primer paso digital real, profesional y accesible**.

Los dos primeros productos son:
1. **Web Express**
2. **Landing Express**

Precio objetivo inicial de ambos: **S/100**.  
Tiempo objetivo de entrega: **24 horas**, siempre que el cliente entregue la información y materiales necesarios.

# 3. PRODUCTO 1 — WEB EXPRESS

## Definición

Web Express es una página web de una sola página para negocios que necesitan una presencia online profesional, sencilla y útil.

No busca reemplazar una tienda online, sistema de reservas, aplicación o plataforma compleja.

Busca resolver:
> “Quiero que cuando alguien busque mi negocio, pueda conocerlo, ver lo que ofrezco y contactarme fácilmente.”

## Objetivo

La web debe responder rápidamente:
- ¿Quién es este negocio?
- ¿Qué ofrece?
- ¿Por qué debería elegirlo?
- ¿Qué puedo ver/comprar/contratar?
- ¿Dónde está?
- ¿Cuándo atiende?
- ¿Cómo puedo contactarlo?

El objetivo principal es generar confianza y facilitar una acción:
- Escribir por WhatsApp
- Llamar
- Reservar una cita
- Pedir información
- Solicitar cotización
- Hacer un pedido
- Consultar disponibilidad
- Visitar el local
- Ver catálogo

# 5. Principios de diseño

Aunque tenga un precio accesible, **no debe sentirse como un producto barato**.

Debe sentirse:
- Profesional
- Moderno
- Claro
- Visual
- Rápido
- Confiable
- Adaptado al negocio
- Fácil de usar desde celular
- Enfocado en el cliente

La reducción de precio se consigue principalmente mediante velocidad, reutilización y procesos eficientes, no sacrificando la calidad visual o la utilidad.

---

# 6. Límites

Para mantener precio y tiempo:
- Una sola página
- Información proporcionada principalmente por el cliente
- No ecommerce
- No sistemas complejos de reservas
- No cuentas de usuario
- No panel administrativo personalizado
- No bases de datos complejas
- No aplicaciones web
- No automatizaciones complejas
- No carga ilimitada de productos
- No rediseños ilimitados
- Una ronda razonable de cambios

Las necesidades fuera de este alcance pueden convertirse posteriormente en servicios personalizados.

# 9. PRODUCTO 2 — LANDING EXPRESS

Landing Express se definirá con mayor profundidad después de cerrar Web Express.

Conceptualmente:
> Una página enfocada en promocionar y convertir sobre **UNA oferta concreta**.

Puede utilizarse para:
- Un producto
- Un servicio
- Una promoción
- Un curso
- Un evento
- Un lanzamiento
- Una campaña
- Una oferta especial

Diferencia fundamental:

**Web Express = presencia del negocio.**  
**Landing Express = promoción y conversión de una oferta.**

La Landing Express tendrá posteriormente su propia **matriz de contexto por tipo de oferta/objetivo**.

# 16. Reglas de Diseño UI — Prohibiciones y Estándares

## ❌ NO usar: Badges / Pills de etiqueta en heroes

**Prohibido** usar elementos tipo badge, pill o etiqueta pequeña encima del título principal en secciones hero. Ejemplos de lo que NO se debe hacer:

```
[ • CLÍNICA VETERINARIA & URGENCIAS 24/7 ]   ← MAL
[ ✦ Servicios de Confianza ✦ ]               ← MAL
[ 🟢 LIVE • Atención disponible ]            ← MAL
```

**Motivo:** Estos elementos se ven genéricos, "template-like" y restan impacto visual al headline principal. Saturan la jerarquía visual y distraen del mensaje central.

**Alternativa correcta:** Ir directo al titular potente. La calidad y el copy deben hablar por sí solos. Si se necesita comunicar disponibilidad o una categoría, hacerlo dentro del subtítulo, en el topbar o en la barra inferior del hero, nunca como badge flotante sobre el h1.
